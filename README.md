#DX.Library Overview
Cross-Platform Library for Delphi / FireMonkey

DX.Library contains various helpers and utilities for Delphi, with a special focus on cross platform development. All code is usually tested on the most current Delphi Version only.

## Supported Delphi versions

We compile and test DX.Library on our build server down to Delphi 10.3 Rio, which is the oldest supported version. Older versions may work, but using them is at your own risk and without specific support. Pull requests for older versions are welcome, but we only test Delphi 10.3 and newer.
